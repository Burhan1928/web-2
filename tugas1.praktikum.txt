 1. apakah yang dimaksud dengan dokumen root?
 : dokumen utama dalam suatu sistem file atau struktur data yang menjadi dasar bagi dokumen atau file lain.

 2. pada apache web server ,apakah dokumen root harus terletak dalam direktori C:\xampp\htdocs? jelaskan jawaban anda?
 : Tidak, dokumen root dalam Apache Web Server tidak harus selalu terletak di C:\xampp\htdocs, tetapi itu adalah lokasi default jika menggunakan XAMPP di Windows

 3. jelaskan apa yang di maksud dengan perintah git: init,clone,remote,add,commit,push,dan checkout?
  git init : Digunakan untuk membuat repository Git baru di dalam folder proyek
  git clone : digunakan untuk menyalin repository dari server ke komputer lokal
  git remote : digunakan untuk mengelola URL repository jarak jauh
  git add : digunakan untuk menambahkan perubahan file ke dalam staging area sebelum commit
  git commit : digunakan untuk menyimpan perubahan yang sudah ditambahkan ke staging area
  git push : digunakan untuk mengirim perubahan dari repository lokal ke remot repository
  git checkout : digunakan untuk berpindah ke branch atau commit tertentu

 5.apa perbedaan variable user dan variable system?
  Perbedaan utama antara variabel sistem dan variabel user terletak pada cakupan dan pengaruhnya dalam sistem operasi, terutama dalam Windows dan Linux.

 6.apa persamaan variable system dan variable konstan ?
  1> menyimpan nilai
  2> dapat digunakan secara global
  3> ditetapkan di awal
  4> mempengaruhi jalannya sistem atau program
  variabel sistem bisa diubah, sedangkan variabel konstan bersifat tetap dan tidak bisa diubah setelah ditetapkan
